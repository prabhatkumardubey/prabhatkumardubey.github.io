# Prabhat Dubey — Portfolio & Resume

Static site (HTML, CSS, vanilla JS). No build step.

## Before publishing
Replace `YOUR-LINKEDIN` and `YOUR-GITHUB-USERNAME` in `index.html`.

## Deploy
1. Create a public repo named `<username>.github.io`.
2. Push these files to `main`.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site goes live at `https://<username>.github.io` within a minute or two.

## PDF resume
Use the "Download PDF" button (opens the print dialog, which has print-specific styles). Choose "Save as PDF".
